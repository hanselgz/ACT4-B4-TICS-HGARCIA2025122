# Explorador Pokémon - ACT4

## Descripción
Esta es una aplicación web interactiva que consume la PokeAPI para mostrar Pokémon en tiempo real. Permite realizar búsquedas instantáneas por nombre y está desarrollada bajo estándares de calidad de código con ESLint y automatización con Husky.

## Tecnologías Utilizadas
- HTML5
- CSS3 (Flexbox y CSS Grid)
- JavaScript Vanilla (ES6+ / Fetch API)
- Node.js & npm
- ESLint (Linter para JS)
- Husky (Git Hooks)

## API Utilizada
- **API:** PokeAPI (`https://pokeapi.co/api/v2/pokemon`)
- **Descripción:** API pública y gratuita que provee datos e imágenes oficiales de Pokémon sin necesidad de clave API.
